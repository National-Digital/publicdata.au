Why votes

Votes tell us what to build next and they tell publishers what people want from their data. Both are useful.

What blocks a dataset

Only the licence. A dataset with no open licence is listed in grey with the reason. Everything else, including awkward formats and pages with no download, is work, and work goes in the backlog.

Build one yourself

Anyone can add a dataset from this list. A command drafts the register entry from the portal page, and the contributing page covers the rest, from the licence check to the pull request.

For publishers

A grey row shows what would make it buildable. A row with votes shows the demand. If you would rather we built from a file you control, send a stable URL and we will switch to it.

Votes are counted once per browser per day and are never tied to a person. The catalogue can be searched at /api/v1/catalogue, the register is /backlog.json and the counts are /api/v1/votes.
