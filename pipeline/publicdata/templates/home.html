Versions

Every release, kept

A dataset here is the version history the portals do not keep. Each release becomes a dated version with the publisher's own file beside it, byte for byte, and a diff against the release before by the declared key. Cite a version URL and it will resolve to the same data in ten years.

The URL contract
  • /d/<slug>/latest/data.csv302 to the newest dated version
  • /d/<slug>/v/{{ keeps.view.version }}/data.csvkeeps its content, cached for a year
  • /d/<slug>/v/{{ keeps.view.version }}/source.{{ keeps.view.ext }}the publisher's file, byte for byte
  • /d/<slug>/v/{{ keeps.view.version }}/manifest.jsonsource URL, fetched-at, SHA-256
  • /d/<slug>/diff/<a>..<b>.jsonrows added, removed and changed by key
  • /d/<slug>/history.tar.zstevery version's Parquet and manifest

Licence first

Every dataset carries a licence id, an evidence URL from the publisher's own statement and the attribution the licence asks for. The build refuses to publish anything that is not open.

Nothing derived

Cells are typed and headers are renamed. Rows are left alone. No rates, rankings or thresholds are added, and a suppressed cell stays suppressed.

Provenance in every file

JSON, Parquet, SQLite and GeoJSON carry the publisher, licence, attribution, source URL and source hash inside the file.

No tracking

The only analytics is a first-party Cloudflare beacon. There are no cookies and no accounts.
