How it works

Change a panel

Press Edit at the top right of a panel to open its settings. Drag fields into Group by, Split by, Sort by and Filter, pick a chart type at the top, and choose sum, count or average beside each number. More fields lists everything else in the dataset. The chart types include bars, lines, areas, scatter plots, heatmaps, treemaps and sunbursts{% if ds.geometry %}, and maps of the coordinates{% endif %}. Add a chart puts a new panel on the dashboard. Drag a panel's title bar to move it, or drag the line between panels to resize.

Filter every panel at once

{% if explore_master %}The chart marked Click to filter the others does just that: click a bar and the other panels show only those rows. Click it again to clear. {% endif %}Any panel can do the same. Open the menu at the left of its title bar and turn on filtering from there.

Share or keep a dashboard

The address bar holds the whole dashboard, so copying it is enough. Save a short link to store the dashboard on this site and get a shorter address. A saved dashboard never changes; saving again after an edit makes a new link. Embed gives a frame you can paste into a web page, with the attribution inside it.

Download what you see

The export button in a panel's settings toolbar downloads the panel as CSV, JSON or Arrow, or a chart as PNG. The copy button beside it puts the same data on the clipboard. The full files are on the dataset page.

How it runs

The page downloads DuckDB and Perspective once, about {{ engine_size }}, then this version's data.parquet ({{ parquet_size }}). Every chart is a query DuckDB answers in the browser, so there is no rate limit and the files stay the only source. A saved dashboard over a dated version keeps showing that version's numbers.{% if ds.geometry %} A map panel draws its background from OpenStreetMap tiles, so while one is on screen your browser asks OpenStreetMap for them and it sees your IP address. The data itself never leaves the browser.{% endif %}
